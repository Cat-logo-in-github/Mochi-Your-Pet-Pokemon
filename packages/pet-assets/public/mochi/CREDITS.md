# Eevee family artwork credits

Mochi is an unofficial, non-commercial fan project. Pokémon names and character designs belong to Nintendo, Creatures Inc. and GAME FREAK. Original Pokémon Mystery Dungeon artwork is credited to CHUNSOFT/Spike Chunsoft and the original rights holders. No affiliation or endorsement is claimed.

Source: PMDCollab/SpriteCollab, pinned revision 989a2b0d7272e382a0fb51bb611f744256adafbc. Original sheets, XML timing, shadows, offsets and complete per-species credit histories are preserved in packages/pet-assets/source.

Community artwork is supplied under SpriteCollab’s CC BY-NC 4.0 submission/use policy. See LICENSE-SpriteCollab.md. These sprite assets are excluded from the application code’s MIT license.

Changes: lossless frame extraction, exact shadow-anchor alignment, integer nearest-neighbor enlargement, atlas packing, source timing conversion at20ms per tick, and a faster walking cycle for the run behavior. Colors/drawings are unchanged. Core behaviors intentionally reuse named available source animations; forms without Eat use a happy Hop reaction.
